Milestone 002: Chaser Observation Interpretation

Map captured visual and sensor evidence into a bounded observer-world input before the generic decision model considers it.

Status: active - planningStarted: 2026-07-17Decision model: trusted inputsRendering source: Milestone 001

High-Level Objective

Perception Boundary

Keep cameras, VLMs, and geometric interpretation outside the generic decision model. They produce explicit observer-world facts.

Decision Input

Actors receive an understood world shape with provenance and uncertainty, not raw images or simulator-global state.

Completion Usage

Interpret A Chaser Capture

Starting state: a chaser front-view PNG and metadata snapshot exist.

Proposed execution: run a Chase observation interpreter against the snapshot artifact.

Success signal: it emits an observer-world record with source, frame, confidence, and normalized understood facts.

Supply Decision Input

Starting state: an actor decision-model adapter is initialized.

Proposed execution: provide the normalized observer-world record at the next decision frame.

Success signal: the decision model consumes the contract without knowing whether facts came from simulation, vision, or another sensor.

Baseline

Milestone 001 produces reproducible rendered front-view evidence with camera and sensor metadata. Chase simulation still derives actor observations analytically from world geometry; it has no image-to-understood-world layer.

Observation Contract

interface ObserverWorldInput {
  source: "simulation" | "front-view" | "vision";
  frameIndex: number | null;
  facts: UnderstoodWorldFact[];
  confidence: number;
  provenance: ObservationProvenance;
}

The decision model consumes this contract. Sensor decoding, image interpretation, and world-semantic mapping remain outside it.

Scope Boundaries

In Scope

Observer-world contracts, provenance, deterministic fixture interpretation, and chaser adapter boundaries.

Out Of Scope

VLM vendor integration, model training, vehicle dynamics, renderer changes, and changing generic decision-model semantics.

Risks And Controls

RiskControl
Vision leaks simulator meta knowledge.Require explicit capture-derived provenance and fixture inputs.
Decision core absorbs perception logic.Keep interpretation outside the core and pass only normalized observer-world records.
VLM uncertainty becomes opaque.Make confidence and source explicit in every understood fact.

Exit Criteria

  1. A stable observer-world input contract identifies source, frame, facts, confidence, and provenance.
  2. One deterministic chaser capture fixture maps into that contract without global simulator data.
  3. The chaser runtime passes normalized input through an adapter boundary.
  4. Regression evidence proves deterministic interpretation and preserves existing chase behavior.
  5. A closeout records the remaining VLM and real-sensor integration work.
